## 📖 项目简介

**QQMailDrive** 是一款将 QQ 邮箱（尤其是早期拥有无限或超大容量空间的账号）打造成个人高性能私有加密网盘的工具。

与传统的邮件网盘不同，QQMailDrive 深入腾讯邮箱底层协议栈，不仅实现了**工业级端到端加密（AES-256-GCM）**，还创新性地打通了 **IMAP 协议专线** 与 **Webmail 网页端 FTN 直传集群** 的双通道协同体系：
- **上传**：首切片走 IMAP 专线保障协议防风控与信令合规，纯数据分片支持 Webmail HTTP 协同直传腾讯云 FTN 集群入库，实现真正双通道并发；
- **下载**：直连 Webmail 二进制数据流（HTTP 302 重定向），彻底消除传统 IMAP 协议中 33% 的 Base64 体积膨胀与 CPU 编解码负担，吞吐量成倍提升；
- **分享**：独创好友点对点邮件直传，接收端后台智能捕获并自动合流至专属隔离空间「收到的文件」，按发件人独立归档，安全不污染主网盘；
- **播放**：内置流媒体 Range Seek 播放器与杜比音频转码，支持一键调用 PotPlayer / VLC 本地专业播放器边下边播。

整套系统 **100% 采用 Go 语言官方标准库** 开发，无任何第三方 CGO 或网络外部依赖，编译出的单文件仅约 **9.5 MB**，绿色纯净，跨平台开箱即用。

## ✨ 核心特性

### 1. 🏎️ 双通道极速传输引擎 (Dual-Channel Engine)
* **HTTP Webmail 极速免 Base64 下载**：
  直连腾讯 Webmail FTN 底层 CDN 存储，以原生二进制字节流极速下载（`302` 重定向直达），省去 33% 的 Base64 编码体积与客户端解码 CPU 消耗。
* **双协议并发混编流水线**：
  下载引擎支持同时调度 **1~8 路 IMAP 专线长连接** 与 **0~8 路 HTTP Webmail 极速通道**，两套异构链路共享动态优先级调度队列，大幅拉高下载峰值带宽。
* **HTTP FTN 集群上传协同与自动熔断**：
  纯数据分片（Part 2 ~ N）支持通过 HTTP 网页端直传 FTN 集群草稿入库；若遇到网页接口频控或网络波动，瞬间自动熔断避让，无缝降级回退至 IMAP 专线，保障 100% 传输成功率。

### 2. 🔒 工业级端到端加密与风控防御 (Security & Compliance)
* **AES-256-GCM 认证加密**：所有文件数据均在本地客户端完成强密码学流式加密后再传输，云端仅见自描述加密分片，服务端与第三方无法解密数据。
* **精密大文件切片**：默认按 `52428799` 字节（约 50.00 MB）精准分片，严谨避让 QQ 邮箱 50MB 临界风控线；下载时采用 `.part` 预分配与 `WriteAt` 随机写入，零多余磁盘占用。
* **小文件智能合包 (Bundle)**：零碎小文件（<5MB）自动归并压缩加密为紧凑大包（`[QMD:BUNDLE]`），大幅减少邮件总封数消耗，保护邮箱配额。
* **规范自描述分片命名**：采用安全自描述密文命名规则（如 `QMD_<hash>_<idx>_<total>_<size>_<mtime>.7z`），彻底消除旧版序号冲突隐患，支持冷备份直接还原。

### 3. 📬 好友点对点安全直传分享系统 (Peer Share Engine)
* **零中转点对点直传**：支持选择单个文件、多个文件或整个目录树一键生成加密分享包，支持自定义发件人昵称与提取码模式。
* **后台智能捕获与自愈**：接收端后台全自动监听收件箱中的提货单（`[QMD:SHARE:BILL]`）与数据切片（`[QMD:SHARE:DATA]`），集齐后自动完成合流。
* **专属空间无污染归档**：收到的分享文件自动存入专属隔离空间「收到的文件」（`QMD_收到的文件`），并在内部以 `发件人昵称_发件QQ号` 建立专属子目录，绝不污染用户的常规个人网盘。
* **跨空间秒级操作**：支持空间之间秒级原子移动（IMAP MOVE）与秒级克隆复制（IMAP COPY）。

### 4. 🎬 流媒体在线边下边播与播放器外放 (Media Streaming)
* **内置流媒体播放看板**：浏览器端内置流媒体播放器，实时展示播放缓冲进度、缓冲用时、实时缓冲速度与分片调度状态。
* **智能 Range Seek 优先寻道**：拖拽视频进度条时，调度引擎立即唤醒急救绿色通道，错峰让道秒开播放。
* **兼容高清杜比音轨**：内置 FFmpeg 音频实时转码通道，自动兼容 AC-3、E-AC-3、DTS 等现代浏览器无法硬解的高规格音轨。
* **PotPlayer / VLC 协议一键外放**：针对 DivX / XviD / AVI 等老旧视频编码，内置协议调用接口，一键唤醒本地 **PotPlayer / VLC** 等专业播放器流式播放。

### 5. 🖼️ 秒开缩略图引擎与负缓存速断 (Thumbnail Engine)
* **轻量内嵌拉取**：图片与视频首帧的高清 WebP 缩略图加密内嵌于第 1 分片邮件正文（MIME Part 1），拉取仅需 ~10KB 正文，完全无需下载 50MB 附件。
* **负缓存瞬时阻断 (Negative Cache)**：对无图文件或不支持预览的特殊格式，首次识别后记录负向缓存，后续访问 0ms 响应，杜绝重复无效的云端网络轮询。
* **防撕裂优雅降级**：无缩略图或加载中自动优雅呈现原生文件分类图标（🎬 / 🖼️ / 📦），彻底杜绝浏览器裂图。
* **本地持久化缓存**：支持本地 SQLite/DB 缩略图缓存（`cache/thumbs.db`），二次打开秒开相册瀑布流。

### 6. 🛡️ 云端存储健康对账与智能自愈 (Consistency Engine)
* **秒级全库对账**：通过快速扫描邮件报头元数据（`X-Drive-Meta`），几秒内完成与云端主索引（`[QMD:INDEX]`）的双向交叉审计。
* **四大健康维度排查**：
  1. **幽灵条目**：主索引有记录但云端切片已被删除，支持一键安全剔除；
  2. **未入库完好孤儿文件**：云端分片完整但索引缺失（严格区分好友分享文件，绝不误判），支持一键补录恢复；
  3. **半残损毁文件**：提前发现缺失分片的问题文件；
  4. **无主残留邮件**：未被任何文件引用的历史冗余垃圾，支持一键 EXPUNGE 彻底物理抹除，释放邮箱容量。
* **误操作自愈**：自动检测并清理因历史异常操作生成的冗余占位条目，不伤及底层数据。

### 7. 🌐 全自动云端漫游与多电脑独立配置 (Cloud Roaming)
* **核心配置漫游**：分片大小、下载并发数、防风控延时、分享昵称等核心配置自动加密持久化至邮箱 `[QMD:CONFIG]`。
* **多电脑独立下载目录绑定**：根据设备唯一物理特征（主机名 + MAC 地址 SHA-256）生成设备识别码（`Computer ID`），办公室台式机、家用电脑、笔记本各拥有独立的本地保存路径，云端独立映射、自动漫游。
* **Webmail 会话漫游**：扫码获取的 sid 会话令牌加密存入云端 `[QMD:SESSION]`，异地新电脑启动自动静默复用，免去频繁掏出手机扫码的繁琐。

### 8. 🎨 现代化 Web 控制面板与分类设置
* **双列分类参数设置**：采用现代化分类侧边栏设计（【账号】、【功能】、【上传】、【下载】），左右独立分栏，设置清晰明了。
* **实时心跳监控与优雅退出**：前端实时检测后端存活状态，服务断开时醒目预警；顶部常驻「⏹️ 退出」按钮，一键安全关闭 exe 进程。

## 🚀 快速上手

### 第一步：获取 QQ 邮箱 IMAP 授权码
1. 电脑浏览器访问并登录 [QQ 邮箱网页版](https://mail.qq.com/)；
2. 点击页面左上角 **【设置】 -> 【账户】**；
3. 向下滚动页面，找到 **【POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务】**；
4. 开启 **【POP3/IMAP服务】**，依页面提示使用绑定手机发送短信，即可生成一串 16 位的**英文授权码**（*注意：这是专用授权码，并非您的 QQ 密码*）。

### 第二步：运行程序

#### 方式 A：直接运行 Release 预编译包（推荐）
下载解压后，双击直接运行 **`QQMailDrive.exe`**。

#### 方式 B：源码一键编译（需 Go 1.22+）
由于本项目 100% 采用 Go 标准库，无需拉取任何第三方依赖，编译仅需 3 秒：
```bash
# Windows
.\build.bat

# 或者直接使用官方命令行编译
go build -ldflags="-s -w" -o QQMailDrive.exe .
```

### 第三步：配置与使用
1. 启动 `QQMailDrive.exe` 后，程序会自动唤起系统默认浏览器打开控制台：  
   👉 **`http://127.0.0.1:18080`**
2. 点击右上角 **【⚙️ 设置】**，在弹出的设置面板中填入：
   - **QQ 邮箱地址**
   - **16 位 IMAP 授权码**
   - **本地下载路径**（点击右侧选择或手动输入）
3. 点击 **保存配置**，顶部状态指示灯显示绿色 **`IMAP通道 已连接`** 即代表网盘初始化就绪！
4. （可选）在【设置 -> 账号】中点击 **微信扫码绑定 Webmail**，即可解锁 HTTP 极速下载与双通道协同上传通道，速度更上一层楼。
5. **上传文件**：直接将电脑里的任意文件或整个文件夹拖拽进浏览器窗口，即可启动自动切片加密上传！

## 📐 存储协议与信令架构

QQMailDrive 在邮箱中采用轻量级专用协议头进行数据与状态管理：

```text
[QMD:DATA]|<fileID>|<hash>|<idx>-<total>|<hash12>   # 个人网盘分片邮件
[QMD:SHARE:DATA]|<shareID>|<idx>-<total>|<hash12>   # 好友加密分享数据切片
[QMD:SHARE:BILL]|<shareID>                          # 好友加密分享提货清单
[QMD:INDEX]|v<version>|<timestamp>                  # 全局主索引快照 (AES 加密)
[QMD:CONFIG]|<timestamp>                            # 多设备云端漫游配置 (AES 加密)
[QMD:SESSION]|<timestamp>                           # Webmail 网页会话凭证 (AES 加密)
[QMD:BUNDLE]|<timestamp>|<count>                    # 小文件归并紧凑合包
```

* **协议直写与风控防御**：
  所有包含敏感索引、配置、缩略图、元数据以及第一分片的邮件，**100% 严格执行 IMAP APPEND 原语直写**，绕开 SMTP/Webmail 的日常发信配额（彻底避让 `-20003` 频控）。
* **多隔离空间物理隔离**：
  所有网盘数据均存放于带 `QMD_` 前缀的自定义邮箱文件夹内（如 `QMD_MailDrive`、`QMD_收到的文件`），完全不会与您的收件箱日常往来邮件发生混淆。

## 💡 常见问题 (FAQ)

<details>
<summary><b>Q1: 为什么提示授权码错误或连接失败？</b></summary>

- 请确认开启的是 QQ 邮箱的 **【POP3/IMAP服务】**，填入的是短信生成的 **16 位字母授权码**，而不是 QQ 密码；
- 授权码中的字母全部为纯小写或大写（不含空格）；若更换过 QQ 密码，原有授权码可能会失效，重新生成填入即可。
</details>

<details>
<summary><b>Q2: 遇到部分视频无法在网页播放怎么办？</b></summary>

- 现代网页浏览器（Chrome / Edge 等）原生仅支持 H.264 / VP8 / VP9 等常见编码，无法硬解部分老旧编码（如 AVI 封装、DivX、XviD、MPEG-4 Part 2）或特定杜比音轨；
- 遇到此类视频，在网页端点击 **【PotPlayer 播放】** 或 **【VLC 播放】** 按钮，程序将自动唤醒您电脑上的本地专业播放器进行极速流式边下边播。
</details>

<details>
<summary><b>Q3: 换电脑或重装系统后，网盘文件如何找回？</b></summary>

- 您的全部网盘目录树、分片数据以及个性化设置均安全加密漫游在您的 QQ 邮箱云端；
- 在任何新电脑上下载本程序，填入相同的 QQ 邮箱与 IMAP 授权码，程序将秒级拉取云端主索引，所有文件与目录瞬间完整恢复。
</details>

<details>
<summary><b>Q4: 什么是「存储对账」，平时需要使用吗？</b></summary>

- 「存储对账」是内置的一键自愈体检功能。如果网络中断、误删了邮箱里的部分邮件，或者想彻底清理无用残留切片，可以点击该按钮；
- 几秒内即可排查出云端与本地索引的差异，并支持“一键补录完好孤儿文件”和“一键彻底清除无主残留邮件”。
</details>
